# EA-Graph research record

This repository is the public, citable audit trail for the study
reported in *EA-Graph: Artifact-Anchored Verification Memory for Coding Agents
under Upstream Drift*.

It complements the paper rather than adding a second scientific claim. The
paper gives the argument and results; this record shows how the design changed,
what was fixed before each round, which decisions were preregistered, which
tests were post hoc, and how anomalies affected the analysis.

## Navigation

- `research_history.md`: chronological study evolution.
- `records/`: disclosure-safe preregistration and determination records.
- `incident_register.md`: all material testbed and execution anomalies.
- `records/05_claim_audit.md`: which conclusions are direct, exploratory, or
  prohibited.
- `artifact_manifest.md`: public/restricted disposition of source artifacts.
- `source_hashes.sha256`: hashes of selected internal source records, generated
  during release preparation.
- `PUBLICATION_REVIEW.md`: unresolved publication decisions.

Worlds are labeled 1--7 exactly as in the paper. The private mapping to
generator identifiers is deliberately absent. One additional world was
excluded in full because its base template was contaminated; it is not used in
any public result table.
