# Sonnet determination

Analyzed population: the same seven paper worlds and 21 sessions.

| Comparison | Wins / losses / ties | Effective n | Exact two-sided p | Status |
|---|---:|---:|---:|---|
| ANCHOR vs PROSE | 4 / 0 / 3 | 4 | 0.125000 | Preregistered hypothesis not supported |
| ANCHOR vs NONE | 3 / 0 / 4 | 3 | 0.250000 | Preregistered hypothesis not supported |
| PROSE vs NONE | 2 / 2 / 3 | 4 | 1.000000 | No detectable difference |

ANCHOR scored 1.000 in all seven worlds. Frequent control ceilings reduced the
effective paired sample, so perfection of one condition is not evidence for a
within-round contrast by itself.

The larger model frequently reconstructed verification infrastructure during a
session. This is evidence for a plausible mechanism behind the ceiling, not a
causal isolation of that mechanism.
