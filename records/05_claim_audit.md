# Claim audit

| Claim | Evidence status | Publication rule |
|---|---|---|
| ANCHOR improves Haiku provability judgment over PROSE and NONE in this testbed. | Direct: 7/7 wins for both contrasts, exact p=0.015625. Test form selected post hoc. | State with model, task, sample, and test-form bounds. |
| ANCHOR improves Sonnet provability judgment over both controls. | Not supported: preregistered p=0.125 and p=0.250. | Do not claim an effect. |
| Structured verification memory may narrow the observed smaller-to-larger-model gap. | Exploratory descriptive pattern; separate rounds, one run per cell, partial timestamp mismatch. | Present as a hypothesis requiring a paired equivalence design. |
| Haiku plus ANCHOR is equivalent to Sonnet. | Not tested; no equivalence margin or randomized paired model comparison. | Prohibited. |
| File-granularity invalidation over-reports affected behaviors. | Direct construction-level comparison across seven clean worlds. | Report as a diagnostic of representation granularity. |
| Repair completion measures epistemic correctness. | Contradicted by withheld-content cases and a catastrophic repair outlier. | Keep repair completion secondary. |
| The practitioner case proves general industrial effectiveness. | No; it is motivating evidence, not a controlled evaluation. | Do not use it as outcome evidence. |
